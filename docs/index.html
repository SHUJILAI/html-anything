How it works

A two-stage pipeline that fixes your intent before painting it.

You write loose intent. A fast model (Haiku) restructures it into clean Markdown with the right shape. Then the renderer (Sonnet) lays down the design.

01

You drop in intent

"Quarterly review for Q3, three sections, focus on shipping velocity." A draft, a transcript, or a one-liner — anything.

02

Optimizer structures it

claude-haiku-4.5 reshapes it into hierarchical Markdown that fits the chosen style's anatomy. Fast, ~1s.

03

Renderer paints HTML

claude-sonnet-4.6 ingests structured content + the locked style prompt, emits a complete self-contained <!DOCTYPE html>.
