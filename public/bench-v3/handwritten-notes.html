Overview

Lumen v0.4 ships the Auto-Blocks engine — an on-device scheduling system that automatically reserves 90-minute deep-work slots before meetings consume available time. This release is grounded in six weeks of closed-beta data from 210 founders and is accompanied by Slack snooze sync, an iOS widget, and team visibility controls.

Discussion Notes

Auto-Blocks Engine

AR walked through the on-device heuristic + ML hybrid. The model is small enough to avoid battery concerns flagged in beta. Key design choice: blocks are created proactively, before the calendar fills — not reactively. PM confirmed this is the primary differentiator vs. competing tools. DO noted the block-creation animation needs a subtle state transition; ticket already open.

Slack Snooze Sync

AR confirmed Slack OAuth scope is minimal — only Do Not Disturb toggle, no message read access. JL flagged that support will get questions about "why is Slack silenced?" and asked for help text in the permission prompt. AR to add one sentence of copy before submission.

iOS Widget

DO demoed the widget at 2× and 3× text sizes — passes. Countdown timer rounds to the nearest minute; PM and SW agreed exact-minute precision is sufficient. App Store screenshots still need final light-mode renders — DO is blocking on this; due by [DATE].

Team Mode

PM re-confirmed the privacy constraint: teammates see block availability (free/busy during a deep-work window) but never meeting titles or details. SW requested a short explainer screen during team-mode onboarding to set expectations. DO will add a single explainer card — no redesign needed, reuses existing modal pattern.

Pricing & Lifetime Deal

SW confirmed the 500-customer cap on the lifetime deal is enforced server-side. PM asked that the in-app upgrade screen shows remaining slots dynamically. AR says the API endpoint is ready; SW needs to wire it to the copy. Both agreed this creates urgency without manufactured scarcity.
