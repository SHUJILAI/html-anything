01 What's New

HEADLINE SHIP auto-blocks engine

Auto-Blocks reads your existing meetings and working-hours constraints, then automatically reserves 90-minute deep-work slots before your calendar can fill up. No manual scheduling step. No friction. Just protected time, applied daily. 

# Auto-Blocks scheduling logic (simplified)
scan_calendar(range="next_7_days")
  → identify free windows ≥ 90min
  → score windows by focus-quality heuristic
  → reserve top-ranked slots as DEEP_WORK_BLOCK
→ 3 blocks placed: Mon 09:00, Wed 08:30, Fri 10:00

02 Core Features in v0.4

1

Auto-Blocks Engine

Heuristic + lightweight on-device model. Learns your scheduling patterns over time. Respects working hours, buffer preferences, and timezone constraints.

on-device heuristic adaptive
2

Slack Snooze Sync

Notifications pause automatically during an active deep-work block. Your Slack status updates to show unavailability — no manual message required. 

# Triggered at block start
slack.status.set(text="In deep work", expiry=block.end_time)
slack.dnd.enable(until=block.end_time)
→ DND active, status synced
3

iOS Widget

Glance at your next scheduled block and a live countdown timer directly from your home screen. No app open required. Supports small and medium widget sizes.

4

Team Mode

View teammates' block availability without exposing meeting titles, attendees, or any sensitive calendar details. Availability-only — privacy preserved by design.

privacy-first availability-only
